# Contributing

## Accepted contributions

- New complete system prompts for any model
- Workspace policies (`AGENTS.md`) and agent specifications
- Ollama Modelfiles
- Versioned updates to existing prompts
- Corrections to outdated entries

## Format

Each file in the model folders must be a complete, paste-ready prompt. Use Markdown for `.md` files. Modelfiles should be plain text.

## Pull request flow

1. Fork the repository.
2. Add your file in the appropriate model folder.
3. Update the table in `README.md`.
4. Open a pull request with a short description of the model and version.
